# 0.5.0 资产资料与影城平面图

资产保留名称、所属区域，新增具体位置（160 字）和备注（1000 字），允许创建时填写和编辑已有资料。新旧资产的绑定与巡检 ID 不变。报告预览、文字分享及 CSV 显示授权资产的位置与备注；CSV 匿名历史导入兼容原格式和新增列，仍不重建资产绑定。

数据库从 v2 非破坏迁移至 v3：assets 新增非空 location/notes，旧资料默认空；v1 通过原 v1→v2 再迁移到 v3。

设置→影城平面图：每个影城本地保存一张背景图及归一化区域/资产标点，不上传。可生成简易区域网格，再用两个对角重画区域矩形；图内新增区域后可标注。可导入 JPG/PNG、选择 PDF 页码导入；文件上限 32 MB，位图最大边约 2048 像素，PDF 页面渲染至 2048 像素。不解析 CDR 矢量对象：仅尝试现代 CDR ZIP 容器中内嵌 PNG thumbnail/preview；没有可用预览的 CDR 请先导出 PDF/JPG。读取预览的限制会明确提示。不能把简易网格当建筑测绘图，不自动推断设备位置。

选择资产/区域再点击标注；可移除标注、重标。替换背景或生成新图会要求确认并清除当前标注，资产、区域和巡检数据库仍保留。第一版不支持多楼层页签、比例尺、CDR 图层编辑或自动识别墙体。

变更：Database/Repository（资料及迁移）；AssetDialogs/MainActivity（创建、编辑、列表、地图入口）；FloorPlan（本地格式处理与绘制标注）；ReportPreview/ReportExport/HistoryImport（授权资产资料导出）；三语资源；版本、发布与验证脚本。保留 Fieldwatch 固定上游、MIT attribution 和固定签名。

验证：v1/v2 升级数据与绑定保留、资料编辑与 CSV 引号兼容、Android PDF/JPG/CDR预览、标注持久化、非法坐标/页码不覆盖原图、简易区域图生成；完整资产、报告、语言、分类与覆盖安装流程。
