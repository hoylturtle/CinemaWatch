# 影城资产巡检闭环（0.8.0）

入口：资产 → 巡检与处理。登记并绑定影院自有设备，固定巡检位置完成真实资产巡检，确认现场正常后建立基线；之后自动比较 RSSI 中位数、离散度与连续未发现记录。基线由人工确认，未确认前显示学习；现场位置或设备变更后重新确认。

异常结果 REVIEW/MISSING/WEAK/UNSTABLE 生成每资产一个活动待办，重复异常追加记录。采样受限、过时/超时、演示、LAB 与导入记录不生成故障待办、不关闭问题。处理可备注、选照片或调用系统相机，照片缩小后存本地私有目录，最大输入 16MB，不上传。处理完成进入 WAITING_RECHECK；只有处理动作后开始的真实合格巡检、存在确认基线并判为 NORMAL 才关闭。异常复检重新待处理，正常但采样受限或此前已开始的扫描不会关单。未发现信号不等于设备损坏。

资产页展示区域待办；平面图点区域查看该区资产，点设备进入维护页，颜色体现最近资产巡检状态。报告突出需要处理和需要重扫的资产，显示后续处理记录；CSV 增加当前处理状态及维护记录，无未登记无线标识。照片保留在本机；CSV 不打包照片。

Room v3→v4 无损迁移新增 asset_baselines、maintenance_issues、issue_events，仅引用授权资产，无顾客无线标识。旧结果保持原样，不自动把旧正常记录当成已人工确认的基线。原 Fieldwatch v1.1.21 / 5379a2049c351c2483f7f106ca68d5d6d5f00e64 和 MIT attribution 保留。

测试覆盖：基线确认限制、模拟/LAB/受限采样隔离、一资产一活动工单、处理前扫描不误关闭、异常复检重开、合格正常复检关单、旧 v3 数据迁移、设备维护 UI 与本地照片。合成数据测试不代表现场 Android 扫描性能；实际巡检需要设备权限、稳定绑定信号与固定巡检位置。
