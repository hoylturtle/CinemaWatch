# 0.4.0 Fieldwatch 分类与国内生态

沿用 Fieldwatch v1.1.21（5379a2049c351c2483f7f106ca68d5d6d5f00e64）原 SignatureEngine、catalog 与 RadioDb，不改上游文件和许可证。

扫描界面保留全部 Signature 命中，展示门禁、音频、摄像设备、无人机、寻物标签、眼镜、健康、家居 IoT、路由器、Mesh 等全部上游类别。点击分类筛选下面的信号列表；可显示或隐藏空分类，显示无线信号总数、类型未匹配数量、多类型匹配数量与规则名称。品牌生态独立展示 Apple、iPhone 名称线索、华为、荣耀、小米、OPPO、vivo/iQOO、realme、一加、大疆、海康、大华、TP-Link/Tapo、中兴。

生态判断：先 BLE 公司名称，再有效公共地址 OUI 厂商，最后广播名称；名称仅低置信线索，厂商中置信，不证明型号、设备所有权或具体协议支持。国内生态规则是本地名称/厂商适配器，没有编造未验证的 manufacturer ID、UUID 或 payload 协议。随机 BLE 地址不用于 OUI 厂商判定。DJI 公司信息本身不证明无人机，海康公司信息本身不证明摄像头。

类型与生态可以重叠；类型行数不可相加作设备数，更不能当人数。Wi-Fi 只表明接入点/热点广播，手机热点可同时属于手机名称线索与接入点。BLE 只有品牌证据而无类型规则时仍列为类型未匹配。

实时列表受既有 512 条内存上限限制；总数为当前可显示信号，不等同完整采样汇总。未经授权标识及 Signature 名称只留在采样期间内存中，结束清除。历史报告维持既有互斥主分组的匿名计数，避免重叠分类改变旧报告含义；实时多标签不落盘。不新增追踪或网络依赖。

变更文件：SignalGrouping（完整类型映射、生态适配、成员集合）、ScanEngine（保留全部匹配）、MainActivity（分组列表/筛选/计数）、ReportPreview 标签资源、三语言 strings、版本与发布配置、SignalGroupingTest 和 FirstRunTest。
