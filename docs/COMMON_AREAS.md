# 影城公共区域（0.3.1）

新建影城：在指定数量的影厅之外，原子创建大堂、通道、办公区和放映层，默认仍选中影厅 1。
已有影城：设置中的“补充公共区域”只为当前影城创建缺失的标准区域，保留区域 ID、资产、报告和当前选择；不会自动修改其他影城。也可通过“新增区域”创建更多通道或其他自定义区域。

区域仍使用既有 Zone 表，不变更数据库结构。名称按创建时界面语言保存，用户区域名称不随语言切换改写；三种语言的标准名称用于补充时去重。

修改：CinemaRepository 的事务创建和补充接口、MainActivity 创建提示和补充入口、三语资源、版本/发布配置、单元与 Android 流程测试。固定包名和固定签名不变，0.3.0 可覆盖更新为 0.3.1。

验证：新增影城含公共区域；重复补充和跨语言补充不重复；仅操作当前影城；资产保留；非法参数整笔回滚；Android 新建与既有资产/报告/语言流程。
