# 多信号融合定位改进方案（研究建议，未实现）

## 先区分三类问题

1. **资产身份/无线关联**：一个授权资产可有多个发射端。当前是人工绑定；未来可基于已登记的服务/制造商字段提出候选，仍需人工确认或设备可验证身份。MAC、OUI、相同名字不能证明同一物理设备。
2. **设备类别判断**：可使用公司号、公开地址OUI、服务UUID、广告结构、Wi-Fi能力等解释类别。广播名称可伪造；不得仅因识别出某品牌就认定为手机、顾客或恶意设备。
3. **区域/几何状态**：标签在哪个区域是分类；手机或资产的米制位置是估计。前者不要求可用几何测距，后者必须有已标定坐标与可观测测量。

未授权访客不得因为新增“指纹”功能就建立跨会话/跨日关联。优先处理已授权设备和短会话汇总；不做随机MAC恢复到个人身份的推断。

## 建议数据合同

`ObservationEnvelope` 至少包含：来源技术、受控资产/会话标识、接收机/发射端profile、单调采集时间及可选墙钟、处理时间、单位、RSSI/距离/方位/位姿类型、有效性原因、样本序号与丢弃计数。对ranging加入成功状态、距离标准差、LOS/NLOS线索、设备能力、参考坐标系；对视觉加入trackingState、重投影/深度质量及协方差。不要把网络RTT或RSSI值装进“米”字段。

现有Observation.at缺硬件采集时间，需Adapter明确标记为receipt_time；不要悄悄改变上游语义。公开数据用生成的会话ID与合成资产，私有原始字段要有留存边界与可验证清理。

## 信号质量与预处理

- 分开广播次数、唯一发射端数、有效时间覆盖、扫描批次与有效接收机数。相同广播重传/重叠窗口不能充当独立证据。
- 保留采集/回调/处理三个阶段时间，检测倒退、漂移、延迟、离线、节流与负载；过期样本不刷新lastSeen或置信度。
- 按接收机、radio、频段、PHY、标签发射功率/间隔维护标定profile；检查手机是否移动或安装姿态改变。资产多radio样本不要直接共用一个RSSI基线。
- 用中位数/MAD等鲁棒统计记录离散度与有效样本比例，隔离异常尖峰、突发包和电池/温度导致的变化。禁止通过增加重复包人为提高置信度。
- 已知LOS/NLOS、金属/墙体遮挡及节点故障有独立原因码，稀疏/冲突证据先输出未知；不默认用RSSI路径损耗换算距离。

## 分阶段区域模型

**基线A：保留现有启发式。** 记录其margin、样本数、未知率、区域切换和时延，作为必须比较的冻结baseline。

**基线B：校准的radio fingerprint分类。** 授权标签走已知网格/区域路线，分别收集不同手机、朝向、日期和人流环境。输入可以是接收机RSSI中位数、离散度、缺失掩码、来源质量及已知发射profile，输出区域概率或集合。训练与测试按整段会话/日期/设备拆分，不把同一滑动窗口随机分到两侧。Wi-Fi指纹首先用于携带采集手机的接收机定位，或已知授权Wi-Fi发射端；它不能从普通AP扫描推导所有顾客手机的位置。

**时序层：区域拓扑约束。** 使用人工平面图建立可达邻接；HMM/状态机/粒子方法只能在质量足够时平滑，不能跨长缺口拼接轨迹、穿墙或把先验当成新测量。需要unknown/out-of-map状态及变化检测；模型在新影城不能沿用未经验证的概率。

**几何融合：单独启用。** 支持的UWB/RTT/视觉惯性/深度以各自噪声模型进入EKF或鲁棒因子图；先解决坐标系、时钟、外参和可观测性。输出误差区域与源贡献，不能假定多个相关RSSI读数相乘就更准确。

## 三种置信度分开

- 身份可信度：是否经过授权登记/可验证设备凭据；名称或MAC匹配仍可能被仿冒。
- 类别可信度：规则/指纹如何支持类别，有哪些替代解释。
- 区域可信度：在匹配部署分布的留出数据上校准；记录概率可靠性、Brier/ECE或等价指标，并与未知覆盖率一起报告。

当前LOW/MEDIUM、6dB领先和“连续两次”都不是上述概率校准。质量差时降低可用性、扩大不确定度或拒判，而不是输出一个精确分数。

## 异常处理与验收

覆盖权限撤回、蓝牙关闭、Android节流、省电、网络掉线/高延迟、节点重启/重复序号、队列溢出、时钟跳变、标签地址变化、同名设备、广播伪装、节点区域配置错误和协调端退出。共享密钥认证的数据也可能内容不真实；需节点登记和测量一致性检查。

公开的验证表应同时包含：区域混淆矩阵、macro-F1/平衡指标、未知率与有效覆盖、P50/P95切换时延、断流恢复、设备/日期外推、不同节点缺失、漂移前后差异。所有数值来自预先冻结协议后的留出实验；本报告不填写假精度、假客流或现场成功率。

研发输出建议：合成回放数据生成器、质量单元测试、跨来源时间/单位合同、经过授权的脱敏场地基准、方法说明与失败样本。要先证明优于现有baseline，再把新融合器列为产品能力。
