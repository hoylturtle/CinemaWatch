# 0.6.0 户型图编辑器

全屏固定画布，底部工具：选择/移动、浏览、墙线、房间/通道、门、设备。连续点选拐点绘制墙线；闭合轮廓后关联已有区域或新建区域。可绘制非矩形房间与通道。网格/直角吸附可关闭。门扇使用两点与开启弧线。设备通过列表选择并标点；拖动已选图元可调整位置，浏览模式支持平移与双指缩放；适应画布复位视角。

已完成的图面更改自动保存在本机；撤销/重做保留最近 30 次图面操作。撤销草稿删除最后拐点，取消清除未完成轮廓；退出时未完成草稿不保存。图面撤销/删除仅影响图元，不删除区域、资产或巡检。第一版是示意图，无实际建筑比例尺、墙厚计算或墙体拓扑自动识别。

PlanPin 增加可选 vertices 列表，旧矩形和设备点坐标仍可读取、显示、移动，原底图保留。墙线/门使用本地独立图元 ID，不涉及无线追踪。原有 PDF/JPG/PNG 导入、CDR 内嵌预览处理保留，导入放在独立弹窗，替换底图仍需确认。资产名称、位置、备注和数据库 v3 不变。

修改：FloorPlan、PlanGeometry、三语资源、版本与发布配置、FloorPlanTest 和几何测试。保留上游固定基线和 MIT attribution，沿用签名。
